# hw-docs

**Resuming work? Read `MISSION.md`:** it has the queue, the full workflow and the open issues.

Hardware reference library. Before searching the web for a board, chip or part spec, check here: `boards/`, `chips/`, `parts/`, each entry's `README.md` first.

- Adding or refreshing an entry: follow the workflow in `MISSION.md` (the same as the `hw-docs` skill in `~/.claude/skills/hw-docs/SKILL.md`, if present).
- Keep the index table in `README.md` in sync when entries are added.
- Each README states facts from the vendor sources. Anything unverified is marked as unverified.
